# Project details

## Scope

This project was developed as a Siemens NX 2412 CAD project covering construction and assembly modelling of a skateboard.

## Workflow

1. Individual part modelling
2. Axle and wheel subassemblies
3. Complete bottom-up assembly
4. Assembly constraints
5. Assembly / disassembly sequencing
6. Exploded-view documentation
7. Engineering drawing creation
8. Collision checking
9. Clone assembly for portable file references

## Main components

- Skateboard deck
- Axle
- Mounting bracket / hanger
- Wheel
- Wheel axle
- Rubber bushing
- Standard fasteners, washers and nuts

## Assembly

The complete assembly contains 16 positions including standard parts and two subassemblies.

The documented mass properties include approximately:
- Deck: 944 g
- Axle: 119 g
- Wheel: 72 g
- Complete skateboard: approximately 1.8 kg

## Drawings

The project includes six individual-part drawings:
- Axle
- Mounting bracket
- Skateboard deck
- Wheel
- Wheel axle
- Rubber bushing

It also includes assembly drawings for the axle subassembly, wheel subassembly and main assembly.

## Verification / quality checks

The CAD assembly was checked for unwanted interference. The documented result was no unwanted penetration, with contact limited to intended areas and threaded connections.

A Clone Assembly workflow was also used to create portable file references and avoid broken absolute-path links.
